# Eliya Sayyed — Portfolio

Responsive personal portfolio for https://eliyaabbas.github.io/.

## Publish on GitHub Pages
1. Put index.html and .nojekyll in the root of the eliyaabbas/eliyaabbas.github.io repository on the main branch.
2. Open repository Settings → Pages.
3. Set source to Deploy from a branch, select main and / (root), and save.
4. Wait for the Pages deployment to complete, then open https://eliyaabbas.github.io/.

## Edit
All content, styles and scripts are in index.html. No build step is required. Open it in a browser to preview. Google Fonts is optional; system fonts are used if unavailable.

Features: responsive sidebar, project filters, expandable project descriptions, experience timeline, email links and copy action, printable portfolio, reduced-motion support and keyboard navigation.

Professional content is based on the supplied resume. Project artwork is illustrative. No client datasets are included.
